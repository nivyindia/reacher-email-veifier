# Nivy Autonomous Start / Continue Command

**START / CONTINUE this repository.** Read the repository purpose, README, current code, plans, issues, and trackers. Identify the highest-priority incomplete and unclaimed task belonging here. Claim it, mark `IN_PROGRESS`, execute, verify with appropriate tests, record evidence/status, commit, release the claim, re-check, and continue automatically. Do not start from scratch or duplicate work. Never expose or commit credentials/secrets. Respect security and human-approval boundaries. Stop only for a genuine blocker requiring human input.

Canonical loop: `CHECK → READ → INSPECT → FIND TASK → CLAIM → IN_PROGRESS → WORK → VERIFY → RECORD → COMMIT → RELEASE → RECHECK → CONTINUE`
